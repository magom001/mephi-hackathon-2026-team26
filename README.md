## Задача

По структурным дескрипторам 751 химического соединения требуется предсказать три показателя биологической активности против вируса гриппа:

- **IC50 (мМ)** — концентрация, подавляющая 50% активности вируса. Чем меньше — тем лучше.
- **CC50 (мМ)** — концентрация, токсичная для 50% клеток. Чем больше — тем безопаснее.
- **SI** — индекс селективности (CC50 / IC50). Чем больше — тем избирательнее действие.

Каждое соединение описано вектором из 210 числовых молекулярных дескрипторов.

Метрика качества:

```
score = (RMSE(IC50) + RMSE(CC50) + RMSE(SI)) / 3
```

## Подход к решению

### 1. Разведочный анализ данных

Перед построением моделей команда провела анализ данных, который определил все ключевые решения:

- **Сильная асимметрия целевых.** Коэффициент асимметрии SI = 15.63; медиана = 4, максимум = 15620 (в 3905 раз больше медианы). Из-за этого в качестве функции потерь была выбрана L1 (MAE) — она устойчива к выбросам в отличие от L2.
- **Малая выборка** (N/p ≈ 3.6): 751 объект и 210 признаков — высокий риск переобучения. Решение: регуляризация и бэггинг.
- **Слабые одиночные связи** признаков с целевыми (макс. корреляция Спирмана: IC50=0.282, CC50=0.292, SI=0.214). Сигнал сосредоточен в многомерных взаимодействиях — применены ансамбли деревьев.
- **18 константных признаков** из 210 — удалены для ядерных методов (во избежание плохой обусловленности матрицы ядра).

### 2. Предобработка

Реализованы два конвейера под разные типы моделей:

- **Для деревьев (HGB, CatBoost, LightGBM):** только импутация медианой (деревья инвариантны к масштабу и нечувствительны к константным признакам).
- **Для ядерных методов (GPR, Ridge):** импутация → удаление 18 константных признаков → стандартизация.

В обучающей выборке обнаружено 24 пропуска (< 0.02% ячеек) — заменены медианой по столбцу.

### 3. Базовые модели

Обучены четыре семейства моделей, каждое с функцией потерь L1:

| Модель | Мешков | Особенности |
|---|---|---|
| HistGradientBoosting | 20 | Гиперпараметры подобраны через RandomizedSearchCV + GroupKFold |
| CatBoostRegressor | 10 | Встроенный bootstrap Bernoulli, subsample=0.8 |
| LightGBM | 20 | num_leaves=31, max_depth=6, subsample=0.8 |
| GaussianProcessRegressor | — | Ядро Матерна ν=2.5 + WhiteKernel, нет бэггинга |

Ключевое наблюдение: корреляция остатков между тремя семействами бустинга составила 0.88–0.98 — они ошибаются на одних и тех же объектах. GPR ошибается принципиально иначе (корреляция с деревьями: IC50/CC50 ≈ 0.85–0.93, SI ≈ 0.47–0.53), что обеспечивает реальное улучшение при объединении в ансамбль.

### 4. Смешивание и калибровка

**Веса моделей** подобраны методом NNLS (неотрицательные наименьшие квадраты) на out-of-fold предсказаниях — тестовая выборка не участвует в отборе:

- IC50, CC50: NNLS-simplex (нормированные веса для устойчивого масштаба)
- SI: равные веса (тяжёлый хвост делает NNLS нестабильным между фолдами)

**Калибровка отсечения** (все величины физически ≥ 0):

- IC50: clip [0, 2001.4] — 1.5 × p99 train, sanity-guard
- CC50: clip [0, 4743.0] — 1.5 × p99 train, sanity-guard
- SI: clip [0, 221] — порог подобран сеткой на OOF-предсказаниях

### 5. Результаты OOF RMSE по этапам

| Этап | IC50 | CC50 | SI | Mean |
|---|---|---|---|---|
| Ridge (baseline) | 345.41 | 494.47 | 788.48 | 542.79 |
| HGB-bag | 330.00 | 463.69 | 788.37 | 527.35 |
| CatBoost-bag | 328.69 | 462.65 | 787.10 | 526.15 |
| LightGBM-bag | 325.89 | 468.70 | 788.29 | 527.62 |
| GPR | 321.62 | 457.05 | 776.75 | 518.47 |
| Ансамбль NNLS | 319.69 | 452.63 | 782.31 | 518.21 |
| **Ансамбль + clip** | **319.66** | **452.63** | **782.05** | **518.11** |

**Kaggle public leaderboard: 266.75**. Финальный ансамбль даёт лучший средний OOF RMSE. При этом по SI лучшей одиночной моделью остаётся GPR, что связано с тяжёлым хвостом распределения SI.

## Воспроизведение результатов

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка данных

Необходимо положить файлы данных в папку `data/`:

```
data/train.csv
data/test.csv
data/sample_submission.csv
```

Данные доступны по ссылке из условия соревнования (закрытые данные лаборатории).

### 3. Запуск ноутбука

```bash
jupyter nbconvert --to notebook --execute solution.ipynb --output solution_executed.ipynb
```

Или открыть `solution.ipynb` в Jupyter и запустить все ячейки последовательно (`Kernel → Restart & Run All`).

Время выполнения: ~5–7 минут. Результат: файл `submission.csv` в корне репозитория.
